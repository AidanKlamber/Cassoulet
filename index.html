Contrôle GPIO autonome par l'IA

🤖
L'IA peut activer elle-même les sorties GPIO du Raspberry Pi et/ou envoyer des commandes à l'Arduino via UART — sans que tu aies besoin d'intervenir. Il suffit de lui dire en langage naturel.
# Exemple : "Cassoulet, allume la lumière du salon" # → L'IA génère et exécute cette commande automatiquement import RPi.GPIO as GPIO import serial # Map des sorties nommées GPIO_MAP = { "lumiere_salon": 18, "ventilateur": 23, "alerte_rouge": 24, "servo_1": 12, } # Communication Arduino via UART arduino = serial.Serial("/dev/ttyAMA0", 9600) def activer_sortie(nom, etat): if nom in GPIO_MAP: GPIO.output(GPIO_MAP[nom], etat) return f"GPIO {nom} → {'ON' if etat else 'OFF'}" def commande_arduino(cmd): # Envoie une commande texte à l'Arduino arduino.write(f"{cmd}\n".encode()) return arduino.readline().decode().strip() # Dans le system prompt de Cassoulet : # "Tu peux contrôler les GPIO. Utilise <GPIO>nom:1</GPIO> # pour activer et <GPIO>nom:0</GPIO> pour désactiver." # "Utilise <ARDUINO>commande</ARDUINO> pour l'Arduino."
Sorties disponibles
• Relais 4ch → appareils 230V
• LED RGB → indicateurs visuels
• Buzzer → alertes sonores
• Servos via PCA9685 (futur bras)
• Ventilateur → refroidissement
• Écran OLED → affichage dynamique
Entrées lues par l'IA
• HC-SR04 → présence détectée
• DHT22 → temp/humidité pièce
• PIR → mouvement (à ajouter)
• INA219 → niveau batterie
• BMP280 → pression/altitude
• TCS34725 → couleur objet
Exemple dialogue
"Il fait chaud dans la pièce ?"
→ Cassoulet lit DHT22 → 28°C
→ Répond + active ventilateur auto

"Quelqu'un est là ?"
→ Lit HC-SR04 + caméra face_recognition
→ "Oui, c'est Aïdan à 1.2m"

Code — Extraits clés

Contrôle GPIO par l'IA (dans extraire_et_executer)

import RPi.GPIO as GPIO import serial GPIO.setmode(GPIO.BCM) SORTIES = {"lumiere": 18, "ventilateur": 23, "alarme": 24} for pin in SORTIES.values(): GPIO.setup(pin, GPIO.OUT, initial=GPIO.LOW) arduino_port = serial.Serial("/dev/ttyAMA0", 9600, timeout=1) def extraire_et_executer(reponse): # Contrôle GPIO : <GPIO>lumiere:1</GPIO> if "<GPIO>" in reponse: import re matches = re.findall(r'<GPIO>(\w+):(\d)</GPIO>', reponse) for nom, etat in matches: if nom in SORTIES: GPIO.output(SORTIES[nom], int(etat)) reponse = re.sub(r'<GPIO>.*?</GPIO>', '', reponse) # Commande Arduino : <ARDUINO>LED:1</ARDUINO> if "<ARDUINO>" in reponse: matches = re.findall(r'<ARDUINO>(.*?)</ARDUINO>', reponse) for cmd in matches: arduino_port.write(f"{cmd}\n".encode()) reponse = re.sub(r'<ARDUINO>.*?</ARDUINO>', '', reponse) # ... reste du traitement (CODE, GRAPH, etc.) ... return reponse

Reconnaissance faciale temps réel

import face_recognition, cv2, numpy as np # Charger encodage connu d'Aïdan img_aidan = face_recognition.load_image_file("aidan.jpg") encoding_aidan = face_recognition.face_encodings(img_aidan)[0] noms_connus = ["Aidan"] encodings_connus = [encoding_aidan] cam = cv2.VideoCapture(0) while True: ret, frame = cam.read() small = cv2.resize(frame, (0,0), fx=0.25, fy=0.25) rgb_small = small[:, :, ::-1] locations = face_recognition.face_locations(rgb_small) encodings = face_recognition.face_encodings(rgb_small, locations) for enc, loc in zip(encodings, locations): distances = face_recognition.face_distance(encodings_connus, enc) best_match = np.argmin(distances) nom = noms_connus[best_match] if distances[best_match] < 0.5 else "Inconnu" # Déclenche action Cassoulet si Aïdan reconnu if nom == "Aidan": parler("Bonjour Aïdan !")
